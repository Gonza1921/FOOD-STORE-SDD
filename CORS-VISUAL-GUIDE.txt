│ FASTAPI ROUTING RULES (for future reference)                          │
└─────────────────────────────────────────────────────────────────────────┘

  Rule 1: Base routes use empty string
  ─────────────────────────────────────
  ✅ @router.get("")
  ✅ @router.post("")
  ✅ @router.put("")
  ✅ @router.delete("")

  ❌ @router.get("/")
  ❌ @router.post("/")
  ❌ @router.put("/")
  ❌ @router.delete("/")

  Rule 2: Dynamic/sub-routes keep slashes
  ────────────────────────────────────────
  ✅ @router.get("/{id}")
  ✅ @router.post("/{id}/confirmar")
  ✅ @router.get("/publico")
  ✅ @router.patch("/{id}/principal")

  Rule 3: Router prefix handles base path
  ────────────────────────────────────────
  router = APIRouter(prefix="/api/v1/things")

  @router.get("")             # = /api/v1/things
  @router.get("/{id}")        # = /api/v1/things/{id}
  @router.get("/search")      # = /api/v1/things/search
