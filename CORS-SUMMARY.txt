🔍 ROOT CAUSE ANALYSIS
──────────────────────

FastAPI has automatic redirect middleware that:
  1. Detects trailing slash mismatch
  2. Issues 307 Temporary Redirect
  3. Browser's CORS preflight cannot follow redirects
  4. Result: CORS blocked

Solution:
  ✅ Make backend routes match frontend requests EXACTLY
  ✅ No trailing slashes in route decorators (use "" not "/")
  ✅ Frontend already correct (centralized API constants)
  ✅ Now both align perfectly, no mismatch, no redirect

🎯 KEY TAKEAWAY
───────────────

The CORS 307 redirect problem was NOT a CORS configuration issue.
It was a ROUTE PATTERN INCONSISTENCY issue.

One backend router (@router.get("/") in direcciones) was out of sync
with the others, causing FastAPI to redirect, which broke browser
CORS preflight handling.

Fix: Make all routers use @router.METHOD("") for base routes.
